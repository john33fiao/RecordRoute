# RecordRoute

RecordRoute는 음성/문서 처리 워크플로를 제공하는 제품입니다.

## 사용 대상

- 로컬에서 RecordRoute UI를 실행해 작업을 시작하려는 사용자
- 처리 결과 확인/재시도를 수행하는 운영 사용자

## 빠른 시작

### 1) 프론트엔드 실행

```bash
cd frontend
npm install
npm run dev
```

### 2) 프론트엔드 빌드

```bash
cd frontend
npm run build
```
