# 화자 분리 KPI 정의

이 문서는 RecordRoute의 화자 분리(Speaker Diarization) 품질을 합의된 방식으로 측정하기 위한 최소 KPI 기준을 정의합니다.

## 1) DER (Diarization Error Rate)

### 정의
- 기본 지표: `DER = (Miss + False Alarm + Confusion) / Reference Speech Time`
- 측정 단위: **퍼센트(%)**
- 보고 방식: 데이터셋별 DER과 전체 가중 평균 DER을 함께 보고

### ignore/silence 처리 규칙
- 참조 정답 기준 **무음(silence) 구간은 DER 분모(Reference Speech Time)에서 제외**
- 평가 제외(ignore) 구간이 정의된 경우, 해당 구간은 분자/분모에서 모두 제외
- 오버랩(동시 발화) 구간은 초기 기준에서 단일 주 화자 정책으로 라벨링된 참조셋에 맞춰 평가

### 평균 방식
- 기본: 파일별 DER을 **발화 시간 가중 평균(weighted average)** 으로 집계
- 보조: 파일별 단순 평균(macro average)도 함께 기록하여 편차 확인

## 2) 화자 전환점 오차

### 선택 지표
- 본 문서는 전환점 지표로 **Precision / Recall / F1** 방식을 채택

### 허용 윈도우
- 참조 전환점 기준 **±0.5초** 이내 예측 전환점을 TP로 처리
- 허용 윈도우 바깥 예측은 FP, 매칭되지 않은 참조 전환점은 FN

### 산식
- `Precision = TP / (TP + FP)`
- `Recall = TP / (TP + FN)`
- `F1 = 2 * Precision * Recall / (Precision + Recall)`

## 3) 요약 품질 영향 측정 방식 (A/B)

### 실험 설계
- A안: 화자 정보 미포함(STT 텍스트만 사용)
- B안: 화자 정보 포함(`segments[].speaker` 반영)
- 동일 입력/동일 프롬프트/동일 모델 설정에서 비교

### 평가 지표
- 자동평가: 요약 정합성 점수(예: 핵심 사실 포함률, QA 기반 정답 일치율)
- 사람평가: 화자 귀속 정확성(누가 말했는지), 요약 명확성(5점 척도)

### 허용 편차
- B안은 A안 대비 자동평가 점수가 **-1.0%p 이하로 하락하면 실패**
- 사람평가(화자 귀속 정확성)는 A안 대비 **+5.0%p 이상 개선**을 목표

## 4) 합격 기준 (환경/데이터셋별)

아래 기준을 모두 만족하면 Phase 0 KPI 합의 완료로 간주합니다.

- 공통(전체 가중 평균):
  - DER ≤ **18.0%**
  - 전환점 F1 ≥ **0.80**
- 데이터셋별:
  - 1:1 대화셋: DER ≤ **12.0%**, 전환점 F1 ≥ **0.88**
  - 3~5인 회의셋: DER ≤ **20.0%**, 전환점 F1 ≥ **0.78**
  - 잡음 환경셋: DER ≤ **25.0%**, 전환점 F1 ≥ **0.70**
- 환경별(실행 인프라):
  - 개발 환경(CPU): 기준 대비 DER +3.0%p 이내, F1 -0.05 이내
  - 운영 환경(GPU): 데이터셋 기준을 그대로 충족

## 5) 리포트 템플릿(최소)

평가 결과 문서는 아래 항목을 반드시 포함합니다.

- 평가 날짜/커밋 SHA/모델 버전
- 데이터셋 버전 및 파일 수, 총 발화 시간
- DER(데이터셋별 + 전체 가중 평균)
- 전환점 Precision/Recall/F1 (허용 윈도우 명시)
- 요약 품질 A/B 결과 및 허용 편차 충족 여부
- 최종 판정: Pass / Fail
