# Weekly Drill Completion Tracker (WBS 7.4.5)

이 문서는 운영 점검 정례화의 **완료 조건(7.4.5)** 달성 여부를 회차 단위로 추적합니다.
정책 원문은 `docs/operations/weekly-drill/README.md`, 점검 절차는 `docs/operations-runbook-scenarios.md`를 기준으로 합니다.

## 1) 누적 요약

- 진행 상태: `0 / 4` 회 완료 (최소 1개월 누적 필요)
- 첫 점검 예정일: `2026-03-02`
- 완료 판정 목표: 최근 4회 누적 + 시나리오 빈도 충족 + 근거 지표 기록 + 액션 관리 조건 충족

## 2) 회차별 결과 인덱스

| 회차일 | 문서 | 시나리오 A | 시나리오 B | 시나리오 C | PASS/FAIL | ready 복귀 시간 | 429 reason 관측 | 미해결 액션 |
|---|---|---|---|---|---|---|---|---|
| - | - | - | - | - | - | - | - | - |

## 3) 7.4.5 완료 조건 체크

- [ ] 최근 4회(최소 1개월) 점검 결과가 `docs/operations/weekly-drill/`에 누적되어 있다.
- [ ] 시나리오 A/B/C 각각의 최소 수행 빈도를 충족한다.
- [ ] 회차별 PASS/FAIL 및 근거 지표(ready 복귀 시간, 429 reason 관측)가 기록되어 있다.
- [ ] 미해결 액션 아이템이 0건이거나, 모든 액션에 책임자/기한이 지정되어 있다.

## 4) 갱신 규칙

1. 회차 문서(`YYYY-MM-DD.md`) 생성 후 본 문서의 인덱스 표를 즉시 갱신합니다.
2. FAIL 발생 시 액션 아이템의 담당자/기한을 같은 커밋에서 명시합니다.
3. 4회 누적 시 체크리스트를 재평가하고 `TODO/TODO.md`의 7.4.5 상태를 갱신합니다.
