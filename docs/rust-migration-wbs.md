# Rust 전환 WBS (Work Breakdown Structure)

이 문서는 `TODO/rust-migration.md`의 단계 전략을 실행 가능한 작업 분해 구조(WBS)로 재구성한 계획서입니다.
목표는 **전체 재작성보다 위험이 낮은 하이브리드 전환**을 통해 성능/운영 안정성을 확보하는 것입니다.

## 1) WBS 개요

- 기준 백로그: `TODO/rust-migration.md`
- 대상 구조: Python 백엔드(`sttEngine/*`) + Rust sidecar/hybrid 도입
- 완료 판정: 계약 동등성(응답 필드/에러 코드/정렬), 성능 기준, 운영 안정성

## 5) 완료 기준 (Definition of Done)

- 기능 동등성: 핵심 read API에서 Python 대비 계약 동등성 95% 이상
- 성능: 전환 대상 API의 p95가 baseline 대비 동급 이상(권장: 30%+ 개선)
- 안정성: canary 기간 심각 장애(서비스 중단급) 0건
- 운영성: 장애 시 Python 폴백/롤백 절차 검증 완료
- 문서성: README/AGENTS/모델별 가이드 문서 동기화 규칙 준수
